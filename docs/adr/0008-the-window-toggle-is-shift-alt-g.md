# The window toggle defaults to SHIFT + ALT + G

The first default was ALT + G. Factorio binds ALT + G to "give green wire", and a custom input with `consuming = "none"` lets both fire, so opening the window swapped whatever the player held, a blueprint included, for a green wire. The GUI smoke test caught it. SHIFT + ALT + G has no vanilla binding; players can rebind it under Controls.
